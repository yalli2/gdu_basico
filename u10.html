부정과거

핵심 문법핵심 어휘예문연습 문제 (4세트)
학습 목표
  • 부정과거 규칙·불규칙 형태를 익힌다
  • 과거의 완료된 사건을 순서대로 말한다
  • 시간 표지와 함께 정확히 쓴다

핵심 문법

규칙형과 철자 변화

-ar: -é, -aste, -ó, -amos, -asteis, -aron / -er·-ir: -í, -iste, -ió, -imos, -isteis, -ieron. 철자: llegué, busqué, empecé / leyó, oyeron, creyó.

불규칙형

강한 어간 동사는 강세 부호 없는 어미(-e, -iste, -o, -imos, -isteis, -ieron)를 씁니다.

어간동사 → yo / él
uestar → estuve/estuvo, tener → tuve/tuvo, poder → pude/pudo, poner → puse/puso, saber → supe/supo
ihacer → hice/hizo, querer → quise/quiso, venir → vine/vino
jdecir → dije/dijo, traer → traje/trajo, conducir → conduje/condujo (3복: dijeron, trajeron)
-ir 어간변화pedir → pidió/pidieron, dormir → durmió/durmieron, sentir → sintió
완전 불규칙ser/ir → fui/fue, dar → di/dio, ver → vi/vio
